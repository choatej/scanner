# Scanner Documentation

This directory captures project documentation, including high-level design notes, implementation details, and a record of the collaboration between the user and GPT-5 Codex.

- `design.md` – Architecture and design decisions.
- `implementation.md` – Implementation notes, module overviews, and development progress.
- `conversation-log.md` – Summaries of key discussion points and decisions made during the assistant/user collaboration.

Documentation will evolve alongside the project as new features are scoped and delivered.
